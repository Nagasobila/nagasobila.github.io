# Privacy Policy

Last updated: 12 November 2026

The Glitch uploader is a private tool used only by the owner of the Glitch YouTube channel to publish videos to that channel.

**What it accesses.** With the owner's permission, the tool uses the YouTube Data API to upload videos, set thumbnails, post a first comment and read view counts on the owner's own channel.

**What it does not do.** It does not collect, store or share data about any other YouTube user or viewer. It has no other users.

**Storage.** The owner's Google access token is kept as an encrypted secret in the owner's private GitHub repository and is never shared or sold.

**Removing access.** Access can be revoked at any time at https://myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

**Contact.** Through the Glitch YouTube channel.
